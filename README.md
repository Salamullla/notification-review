# مراجع الإشعارات — V2

نسخة منصة مبنية بـ Next.js ومهيأة للتوسع إلى Frontend + Backend + Database + API integrations.

## التقنية
- Next.js + TypeScript
- Supabase للبيانات
- API Route داخلي لتحميل المعايير
- واجهة RTL محسنة لمراجعة الإشعارات

## التشغيل
1. انسخ `.env.example` إلى `.env.local`.
2. ضع Supabase publishable key.
3. شغل `npm install` ثم `npm run dev`.

## النشر
موصى بـ Vercel مع إضافة متغيرات البيئة الموجودة في `.env.example`.
